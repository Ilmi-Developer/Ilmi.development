# Security

The dashboard holds children's personal data. If you think you've found a
security problem (for example, someone seeing classrooms they shouldn't, or
signing in without a password), don't post it publicly. Report it privately
from this repository's **Security** tab (**Report a vulnerability**), with
what you saw and how to repeat it.

Nothing personal or secret belongs in this repository: pupil and staff details
live only in the database, and passwords, API keys and addresses only in
Railway variables.

To stop someone's access straight away, an admin can turn off their account on
**Manage users**; that also signs them out everywhere.
